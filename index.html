Corrective Actions documents

Choose any folder of employee documents, for example Disciplinary Actions & Terminations, EmployeeRelationsSourceFile or EmployeeRelationsSourceFile2026. Each employee is found from a folder named Last, First at any depth. Choosing a folder replaces only the entries for that folder; everything else is kept, and the same file found twice is counted once. Only file names and dates are read; documents are never opened or uploaded.

Documents repository (open files from the dashboard)

Documents are opened from the private GitHub repository using a read-only key. The key is stored encrypted and is only given to users who have Corrective Actions access. Create it at GitHub → Fine-grained tokens: Only select repositories → employee-relations-documents, Repository permissions → Contents: Read-only. Status:

Publishing encrypts each user's data with their own password and saves it to GitHub.
