Workday repository (HR task tracker)

Workday tasks, statuses and comments are saved in a private GitHub repository with a key that can write (fine-grained token, only that repository, Contents: Read and write). The key is stored encrypted and given only to admins and users with the Workday permission.

A program (IAP) is a named group of Module IDs. Every enrollment with one of those IDs is labelled with the program, so it appears under Program on the dashboard and can be used in user permissions. Each Module ID is its own selection (one title can have several IDs, e.g. IAP2025 and IAP2026) and belongs to one program at a time.
